## Sobre este repositório

Os notebooks jupyter aqui são explorações de dados de Empenhos financeiros do FMD (Fundo Municipal de Desenvolvimento Social) da Prefeitura de São Paulo de 2019 a 2024 que primariamente foram gerados pelo consumo da API do SOF e posteriormente incrementadas as informações de geolocalização (ainda não completo) e da informação de "SEI RESTRITO" onde não foi possível extrair dados adicionais.

Os dados de distritos e subprefeituras foram exportados no QGIS integrado ao Geosampa

Enfim todos os dados são abertos e o objetivo a princípio é observar a destinação geográfica do FMD na cidade, no decorrer do processo alguns insights apareceram.
